(static) applyTheme(theme) → {ThemeApplyResult}

Applies a theme to the browser.

This function sets the specified theme as the active theme and updates all visual elements accordingly. If the theme application fails, the previous theme state is preserved.

Parameters:
Name Type Description
theme Theme

The theme object to apply
Source:
  • themes.js, line 91
Throws:

If the theme parameter is not a valid Theme object

Type
TypeError
Returns:

Result object indicating success or failure

Type
ThemeApplyResult
Example
// Apply a custom dark theme
const darkTheme = {
  id: 'dark-mode',
  name: 'Dark Mode',
  colors: {
    primary: '#bb86fc',
    secondary: '#03dac6',
    background: '#121212',
    text: '#e1e1e1'
  },
  isDark: true
};

const result = applyTheme(darkTheme);
if (result.success) {
  console.log(`Applied theme: ${result.themeId}`);
}
